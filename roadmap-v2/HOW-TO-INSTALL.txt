ROADMAP VERSION 2 - how to add these files to your project
==========================================================

Files:
  ENGINE-ROADMAP.md   (version 2 - replaces your current one)
  ASSET-KIT.md        (new - detail file for F4)
  STUDIO-APP.md       (new - detail file for F9)

WHEN: after you approve F2 Part A and Claude Code has committed it.
      (Don't mix it into the F2 review.)

Then give Claude Code this prompt:

  I have a new ENGINE-ROADMAP.md (version 2), plus ASSET-KIT.md and
  STUDIO-APP.md. They are in <the folder where you saved them>.
  1. Copy ASSET-KIT.md and STUDIO-APP.md into the project root.
  2. Replace ENGINE-ROADMAP.md with version 2, but carry over from the
     current file: the commit hashes for F1 and F2, and any changes made
     to the plan during F1 and F2 work. Set F2 to its real status.
  3. Update the "Current status" section of HANDOFF.md to point to the
     build order in ENGINE-ROADMAP.md section 2.
  4. Show me what changed, then commit as "Docs: roadmap version 2".
  Then continue with F2 Part B as normal.

  From now on, use quick tests for each Part A/B review: run --check on all stories, do the R1 comparison using the 12 frames and the timing data only (no full renders of old stories), and render one demo video of 2 minutes or less for the new feature, with all 10 checks. Keep the F2 demo stories to 2 minutes or less. Full renders of every story and the 12-minute test happen only at milestones (after build steps 4, 7, 10, 13), or if a step changes rendering, audio or voices. Add this as rule R14 when we install roadmap version 2.
